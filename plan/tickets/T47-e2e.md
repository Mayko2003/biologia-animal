# T47 — Pruebas E2E con Playwright

**Épica**: E6 Cierre · **Depende de**: T45 (o T46 si se hizo)

## Objetivo

Pruebas de punta a punta de los recorridos principales sobre el build de producción.

## Dependencia nueva

```bash
pnpm add -D @playwright/test@1.63.0
pnpm exec playwright install chromium
```

## Archivos

- Crear: `playwright.config.ts`, `tests/e2e/navegacion.spec.ts`, `tests/e2e/ficha.spec.ts`, `tests/e2e/busqueda.spec.ts`,
  `tests/e2e/comparador.spec.ts`
- Modificar: `package.json` (script `test:e2e`)

## Pasos

### 1. Configuración

`playwright.config.ts`:

```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: 'tests/e2e',
  fullyParallel: true,
  retries: 0,
  use: { baseURL: 'http://localhost:3100', trace: 'on-first-retry' },
  projects: [
    { name: 'escritorio', use: { ...devices['Desktop Chrome'] } },
    { name: 'movil', use: { ...devices['Pixel 7'] } },
  ],
  webServer: {
    command: 'pnpm start --port 3100',
    url: 'http://localhost:3100',
    reuseExistingServer: !process.env.CI,
    timeout: 60_000,
  },
});
```

`package.json` → `"test:e2e": "next build && playwright test"`.

Confirmá que `vitest.config.ts` solo incluye `tests/unit/**` (para que Vitest no intente correr los `.spec.ts`).

### 2. Pruebas

Usar selectores accesibles (`getByRole`, `getByLabel`, `getByText`). Nada de selectores CSS frágiles.

**`navegacion.spec.ts`**
1. Inicio → clic en "Mapa conceptual embrionario" → URL `/mapa`.
2. En el mapa, clic en el nodo "Protostomados" → URL contiene `sel=protostomia` → el panel muestra "Phyla incluidos (11)".
3. Clic en el nodo "Annelida" → panel con "Clases disponibles" y los links "Polychaeta", "Oligochaeta", "Hirudinea".
4. Clic en "Oligochaeta" → URL `/grupo/oligochaeta` y `h1` "Oligochaeta".
5. Árbol: `/arbol`, escribir "insecta" en "Filtrar grupos" → aparece "Insecta"; clic → panel; clic en "Ver ficha completa" → `/grupo/insecta`.
6. Vista gráfica: `/arbol?vista=grafico&sel=insecta` muestra el texto "Insecta" en el SVG.
7. Lente: `/mapa?lente=cavidad` muestra la leyenda con "Acelomado" y "Pseudocelomado".

**`ficha.spec.ts`**
1. `/grupo/annelida`: existen las secciones "Resumen", "Desarrollo embrionario", "Sistemas"; la tabla de embriología muestra
   "Origina la boca (protostomía)" heredado de Protostomia.
2. `/grupo/annelida#sistema-excretor`: la pestaña "Excretor" tiene `aria-selected="true"`.
3. Filtro: activar "Solo apuntes" → no hay ningún elemento con el texto que empieza con "Externo ·"; volver a "Todas las fuentes".
4. Abrir una insignia de fuente "Apunte · TP6…" → se ve la cita.
5. `/grupo/no-existe` → texto de la página 404.

**`busqueda.spec.ts`**
1. Escribir "nefridios" en la caja del encabezado (solo proyecto escritorio) + Enter → `/buscar?q=nefridios` con un resultado "Annelida".
2. Clic en la coincidencia "Excretor" → `/grupo/annelida#sistema-excretor`.
3. `/buscar?q=anelidos` encuentra "Annelida".

**`comparador.spec.ts`**
1. `/comparar?a=annelida&b=arthropoda` → texto "Ancestro común" y link "Protostomia".
2. Botón "Intercambiar A y B" → URL con `a=arthropoda&b=annelida`.
3. Desde `/grupo/mollusca` → "Comparar con…" → el selector "Grupo A" tiene Mollusca seleccionado.
